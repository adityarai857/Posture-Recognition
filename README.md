
# 🧍 AI-Based Posture Recognition System

An AI-based web application that uses computer vision techniques to recognize and analyze human posture in real time.

## 🎯 Project Objective

The objective of this project is to demonstrate how computer vision and AI-based techniques can be used to recognize and analyze human posture through a web-based application.
